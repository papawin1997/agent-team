ผลกระทบกว้างกว่า PM: planning และ security ใช้ guard แบบเดียวกันและต้องส่ง JSON ผ่าน StructuredOutput เหมือนกัน ตอนนี้จึงรัน DESIGN ไม่ได้เลย ส่วน security ที่เป็น advisory จะ "ตรวจไม่สำเร็จ" ทุกครั้ง (ข้อนี้ยังไม่มีใน log เพราะ run ไม่เคยผ่าน REQUIREMENTS ไปได้ แต่ไล่โค้ดแล้วเข้าทาง deny เดียวกัน) และแต่ละรอบเสียเงินประมาณ $0.08–0.10 × 3 ครั้ง (รวม retry) โดยไม่ได้อะไรเลย
